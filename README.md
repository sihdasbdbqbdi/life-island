# 人生小岛

主持人统一操作的线下派对大富翁。采用暗黑竞技卡通风格；原地图18格、烧烧卡80张。

## 网站版

网址：https://sihdasbdbqbdi.github.io/life-island/

代码备份：https://github.com/sihdasbdbqbdi/life-island

主分支更新后自动运行规则测试、构建并部署到 GitHub Pages。iPad 建议横屏打开 Safari；进度仅保存在当前浏览器，换设备需导出、导入存档。iPad 真机触摸、音效与流畅度仍待现场验证。

## 直接使用

打开 `便携版/人生小岛.html`，无需联网。请把整个便携版文件夹一起带走，原卡图片用于查看原文。

添加玩家 → 开轮随机排序 → 当前玩家用数字键盘录入本轮新增积分 → 点击骰子连续掷骰 → 次数用完后下一位 → 本轮结算。

进度自动保存在当前浏览器。换电脑、移动便携版文件或清理浏览器前，先从“存档”导出 JSON，再在新位置导入。网站版与便携版的浏览器存档相互独立。

## 已实现

- 玩家管理，默认3积分一次，剩余积分跨轮累计。
- 每轮先随机排序，逐人弹窗录分（自动累计余分）；当前玩家用完所有可掷次数后才换人，仅不足一次的余分留到下一轮。
- 重来当前轮：恢复轮初积分、资金、位置、状态、牌堆，重新排序；可撤销。旧版正在进行的轮次缺少轮初备份，此功能从下轮开始可用。
- 位置跨轮延续，每轮结束记录位置及资金；美元弹出、减速后加速飞入排行榜，到账数字增长与玩家回弹。
- 12面骰立体滚动、落骰音效（可关闭）、棋子逐格移动；动态按玩家着色并合并摘要。
- 原图18格：普通格落点奖励、向前经过起点200元、4个烧烧卡格。
- 80张烧烧卡完整录入：直接效果自动结算，猜拳/投票等输入结果；少数歧义卡使用主持人裁定与提醒。
- 连抽排队、持续状态、实时排名、轮末快照、最近20步撤销。
- 浏览器自动保存、导入导出、待结算卡恢复、同浏览器多窗口冲突提示。
- 桌面与窄屏布局；主界面仅保留必要文字，规则收在手册。

## 明确的默认解释

初始资金0；允许负资金；向后经过起点不领奖。失去一次行动扣3分、不移动；暂停本轮保留积分并换人。最富/最穷按当场资金，并列随机。地图最近按环形最短距离，并列随机。交换、绑定、代扣与轮末挑战已自动处理，具体约定见网页“玩法说明”。

## 开发

源码在 `web/`。Node.js 22，首次运行 `npm ci`。

- `npm run dev -- --port 5173`：本机预览。
- `npm test`：规则测试。
- `npm run build`：生成网站静态文件 `web/dist/`。
- `npm run portable`：构建并生成便携版。

界面库锁定 `animal-island-ui@1.9.0`，React锁定18.3.1，避免接口变动。没有后端、账号、云同步或在线支付。
